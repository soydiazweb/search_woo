# search_woo
Plugin para woocommerce para reporte de busqueda de productos

=== search_woo ===
Contributors: Jonathan Diaz
Tags: woocommerce, search, ajax, analytics
Requires at least: 6.6
Tested up to: 7.1
Requires PHP: 8.1
Stable tag: 1.0.0

Buscador AJAX independiente para WooCommerce con shortcode [search_woo], índice propio, sinónimos, coincidencia aproximada y reportes.

== Instalación ==
1. Active el plugin.
2. Ejecute `wp search-woo reindex`.
3. Inserte `[search_woo]` donde corresponda.

La desactivación no elimina ajustes, índice ni reportes.
